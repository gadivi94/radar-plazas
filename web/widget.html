Widget de plazas para tu web

¿Tienes una academia, un blog de oposiciones o la web de un ayuntamiento? Copia este código y mostrará las plazas abiertas que elijas, actualizadas cada día. Es gratis.

<div data-radar-plazas data-sector="seguridad" data-lugar="Cataluña" data-limite="8"></div>
<script src="https://radaropos.com/widget.js" async></script>

Opciones

data-sectorseguridad, sanidad, justicia, educacion, social, transporte, empresas, militar, subalterno, administrativo, oficios, tecnico
data-subtipoUna subcategoría, por ejemplo policia-local, bomberos, tcae, tramitacion
data-lugarUna comunidad (Cataluña, Madrid…)
data-limiteNúmero de plazas (máximo 20)
